## 4. Traps for the next session (each cost real time today)

- **The Claude GitHub connector cannot write `.github/workflows/`** (403,
  missing workflows scope) — and post-transfer it cannot write to the org
  repo AT ALL (OAuth app restriction). All shipping goes via a Mac clone.
- **The Cowork mount can't unlink files** — clone to `/tmp` (CLAUDE.md rule);
  `ops/git_on_the_mount.sh` if you must touch the mount.
- **Two sandboxes**: the session sandbox is NOT the Mac. Build/test in the
  sandbox, ship via Desktop Commander on a Mac `/tmp` clone (proven pattern:
  write small patch scripts, assert on exact strings, run, pytest, push).
- **Supabase function deploys**: no CLI on the Mac; the dashboard Code tab
  edits + "Deploy updates" works (Chrome extension can drive it). Secrets
  apply per-invocation but redeploy anyway after changing one.
- **Per-code pack overrides can't serve two bases** — Coke Zero and broccolini
  both reproduced the camembert trap this weekend (one caught latent, one
  caught by another session within the hour). An override needs the *priced
  unit*, not the physical carton. When Zak says "case of 12", ask which one
  the invoice line prices.
- **Zak's authority settles identity, never unit physics** — the Aperol
  regression proved it; unit-clashing merges hold for conversions no matter
  who confirmed the identity.
- **GitHub settings pages froze the Chrome extension repeatedly** (CDP
  timeouts on Save). Verify a settings change with a fresh page load; if it
  didn't stick, it didn't happen — and check whether the setting even
  matters before fighting it (the PAT-approval one didn't: owners
  auto-approve).
